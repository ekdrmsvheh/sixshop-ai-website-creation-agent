# 01 Project Summary

## 목적
식스샵 프로의 AI 웹사이트 제작 에이전트가 어떤 사용자 문제를 해결하고, 어떤 제품 가치와 비즈니스 임팩트를 만들어야 하는지 정의한다.

## 한 줄 정의
초보자부터 전문가까지 웹사이트 제작자가 더 빠르고 명확하게 사이트 초안을 만들고 수정할 수 있도록 돕는 AI 제작 에이전트.

## 배경
- 식스샵 프로는 쉬운 시작과 유연한 확장을 동시에 제공해야 한다.
- 사용자는 웹사이트를 만들 때 구조, 콘텐츠, 디자인 톤, 수정 방향을 동시에 결정해야 하며 이 과정에서 막히기 쉽다.
- AI는 단순 추천이나 채팅 응답을 넘어 페이지, 섹션, 블록 단위의 제작 실행을 도와야 한다.

## 핵심 사용자
| 사용자 유형 | 주요 니즈 | 예상 어려움 |
|---|---|---|
| 1인 브랜드 / 소상공인 | 빠르게 그럴듯한 사이트 제작 | 구조 설계, 문구 작성, 디자인 감각 부족 |
| 성장 중인 브랜드 | 브랜드에 맞는 페이지 개선 | 전환 중심 구성, 콘텐츠 정리 |
| 에이전시 / 전문가 | 제작 시간 단축과 커스터마이징 | 반복 작업, 초안 생성, 세부 수정 효율 |

## 해결하려는 문제
- 사용자가 빈 화면에서 무엇부터 만들어야 할지 모른다.
- AI가 만든 결과의 의도와 수정 가능 범위가 명확하지 않다.
- 채팅과 실제 웹사이트 편집 결과가 분리되어 느껴지면 신뢰와 통제감이 떨어진다.
- 초보자에게는 쉬워야 하고, 전문가에게는 충분히 유연해야 한다.

## 제품 원칙
- AI는 의인화된 상담원이 아니라 웹사이트 제작을 실행하는 작업 에이전트로 인식되어야 한다.
- 사용자는 AI가 무엇을 만들고 있는지, 왜 그렇게 만들었는지, 어디에 반영됐는지 이해할 수 있어야 한다.
- 결과물은 언제든 사용자가 직접 수정할 수 있어야 한다.
- 대화 UI는 채팅방이 아니라 제작 워크스페이스의 일부여야 한다.

## 성공 지표 후보
| 영역 | 지표 후보 |
|---|---|
| 제작 시작 | AI 제작 시작률, 첫 생성 완료율 |
| 제작 효율 | 첫 페이지 생성까지 걸리는 시간, 섹션 수정 횟수 |
| 결과 만족 | 생성 결과 사용률, 재생성률, 직접 편집 전환율 |
| 비즈니스 | 사이트 공개 전환율, 유료 플랜 전환율, AI 기능 재사용률 |

## 아직 정해야 할 질문
- AI 제작 에이전트의 1차 성공 경험은 사이트 전체 생성인가, 첫 페이지 생성인가, 첫 섹션 생성인가?
- 사용자는 AI를 어느 정도까지 자율적으로 작업하는 존재로 기대해야 하는가?
- AI의 판단 근거는 기본 노출할 것인가, 요청 시 보여줄 것인가?
- 초보자와 전문가에게 같은 인터페이스를 제공할 것인가, 모드나 깊이를 다르게 둘 것인가?
