# 03 Visual Direction

## 목적
AI 웹사이트 제작 에이전트가 사용자에게 어떤 인상으로 보일지 정의하고, 채팅 UI와 제작 UI가 하나의 경험으로 느껴지도록 시각 방향을 정리한다.

## 디자인 방향
AI는 친근하지만 과하게 캐릭터화되지 않은 제작 파트너로 보인다. 화면은 채팅방보다 작업 공간에 가깝고, 사용자는 대화하면서 실제 웹사이트가 만들어지고 있다는 감각을 받아야 한다.

## AI 정체성 표현
| 요소 | 방향 | 이유 |
|---|---|---|
| 이름 | 역할 중심 명칭 사용 | 기대 기능을 명확히 함 |
| 프로필 이미지 | 작고 절제된 아이콘 또는 생략 가능 | 과한 의인화 방지 |
| 말투 | 친절하고 실무적인 톤 | 초보자에게 안심감, 전문가에게 신뢰감 |
| 메시지 형태 | 본문형 중심 | 긴 설명과 결과 요약의 가독성 강화 |
| 작업 결과 | 카드 / 미리보기 / 액션 버튼 | 실제 제작 대상과 연결 |

## 사용자와 AI의 시각적 구분
| 주체 | 시각 표현 |
|---|---|
| 사용자 | 오른쪽 정렬 말풍선, 간결한 입력 강조 |
| AI | 왼쪽 또는 본문 흐름, 말풍선 없이 넓은 텍스트 영역 |
| 시스템 상태 | 중립적인 상태 행, 진행률, 체크 아이콘 |
| 생성 결과 | 페이지/섹션 썸네일과 주요 액션 |

## 톤 앤 매너
- 과하게 감성적인 캐릭터보다 신뢰감 있는 제작 도구에 가깝게 표현한다.
- 빈 화면의 막막함을 줄이되, 사용자가 통제권을 잃었다고 느끼지 않게 한다.
- 초보자에게는 쉽게, 전문가에게는 방해되지 않게 정보 밀도를 조절한다.
- AI의 자신감 있는 표현은 결과 확인과 수정 가능성을 함께 제공할 때만 사용한다.

## 컴포넌트 방향
| 컴포넌트 | 역할 |
|---|---|
| 사용자 말풍선 | 사용자의 요청 기록 |
| AI 본문 메시지 | 제작 안내, 제안, 요약 |
| 작업 체크리스트 | 생성 과정의 투명성 |
| 결과 카드 | 페이지/섹션/블록 단위 결과 확인 |
| 선택 버튼 | 빠른 방향 선택 |
| 수정 액션 | 다시 생성, 이 톤으로 변경, 섹션 추가, 문구 다듬기 |
| 판단 근거 영역 | 포트폴리오/설득 근거가 되는 설계 의도 표시 |

## 레퍼런스 관찰 포인트
- AI 이름과 아이콘이 주는 존재감의 강도
- 사용자 말풍선과 AI 본문형 응답의 대비
- 생성 결과가 채팅 안에 갇히지 않고 작업 대상으로 이어지는 방식
- 진행 상태, 적용 결과, 수정 액션의 명확성

## 확인할 질문
- AI 이름을 제품명에 가깝게 둘 것인가, 역할명에 가깝게 둘 것인가?
- 브랜드 톤은 친근함과 전문성 중 어느 쪽을 더 우선할 것인가?
- AI 메시지 안에서 결과 카드를 얼마나 강하게 보여줄 것인가?
- 작업 진행 상태를 채팅 타임라인에 남길 것인가, 별도 패널로 분리할 것인가?
